# Upstream source

This validation case is derived from:

`beast-base/src/test/resources/beast.base/examples/beast2vs1/testBirthDeathAsYule.xml`

in the BEAST 3 repository.

The upstream example uses 100 taxa, a fixed tree, a zero-death
`BirthDeathGernhard08Model`, and the BEAST-3-only `OneOnX` prior. The
cross-backend adaptation is documented in the parent `README.md`.
