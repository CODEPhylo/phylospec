# testTipDates

## Purpose

This example is derived from the `testTipDates.xml` file distributed with
BEAST 2.7.7. It extends the cross-engine validation suite from contemporaneous
taxa to an alignment whose taxa have different sampling dates.

The inputs are maintained as:

- `reference/beast2-original.xml`: the unmodified BEAST 2 example;
- `reference/beast2-aligned.xml`: the controlled BEAST 2 comparison model;
- `testTipDates.nex`: the original 17-taxon dengue alignment;
- `testTipDates.phylospec`: the manually maintained PhyloSpec model.

The PhyloSpec source is not generated by translating the XML.

## Controlled model

All five paths represent:

- the 17-taxon, 1,485-site dengue nucleotide alignment;
- fixed sampling dates from 1956 through 1994;
- taxon ages measured backwards from the most recent sample:
  - `D4ElSal94` has age `0`;
  - `D4Philip56` has age `38`;
- one HKY substitution model;
- `kappa ~ LogNormal(logMean=1.0, logSd=0.5)`;
- fixed equal base frequencies `[0.25, 0.25, 0.25, 0.25]`;
- `populationSize ~ LogNormal(logMean=3.0, logSd=1.0)`;
- an estimated tree with a constant-population coalescent prior;
- `clockRate ~ LogNormal(logMean=-4.6, logSd=0.5)`;
- an estimated strict molecular clock;
- no gamma-distributed rate variation;
- a chain length of 10,000,000 and random seed `1234`.

The taxon names in the Nexus alignment end in two-digit sampling years. Since
all samples belong to the same century, PhyloSpec can parse the dates with:

```text
date=parse(regex=".*([0-9]{2})$")
```

Both backends convert those dates to ages relative to the most recent sample.
The aligned BEAST 2 XML expresses the equivalent information with a
`date-forward` `TraitSet`.

## Why the aligned XML differs from the original

The original BEAST 2 example contains uncertain-date priors for two taxa and
uses `TipDatesRandomWalker` operators. Those features combine two separate
questions:

1. whether fixed dated taxa are constructed consistently;
2. whether uncertain sampling times and their operators are implemented
   consistently.

This first-stage benchmark isolates the first question. It keeps the original
alignment and fixed sampling dates but removes the two uncertain-date priors.
It also replaces missing or improper parameter priors with explicit proper
log-normal priors shared by all five paths.

Uncertain tip dates should be added later as a separate extension after this
fixed-date benchmark passes.

## 1. Aligned BEAST 2 reference

```bash
mkdir -p validation/target/testTipDates/beast2-reference

{
  /usr/bin/time -p "/Applications/BEAST 2.7.7/bin/beast" \
    -beagle \
    -beagle_CPU \
    -beagle_double \
    -overwrite \
    -seed 1234 \
    -prefix "$PWD/validation/target/testTipDates/beast2-reference/" \
    "$PWD/validation/examples/testTipDates/reference/beast2-aligned.xml"
} 2>&1 | tee \
  validation/target/testTipDates/beast2-reference/testTipDates-beast2.run.log
```

## 2. PhyloSpec to BEAST 3 direct

```bash
mkdir -p validation/target/testTipDates/beast3-direct

mvn -pl validation/beast3/java -am \
  -Pvalidation-beast3-direct \
  -DskipTests \
  -Dphylospec.validation.source=validation/examples/testTipDates/testTipDates.phylospec \
  -Dphylospec.validation.outputPrefix=validation/target/testTipDates/beast3-direct/testTipDates-direct \
  -Dphylospec.validation.seed=1234 \
  -Dphylospec.validation.expectedLog=validation/target/testTipDates/beast3-direct/testTipDates-direct.log \
  -Dphylospec.validation.operatorSummary=validation/target/testTipDates/beast3-direct/testTipDates-direct.operators.txt \
  verify 2>&1 | tee \
  validation/target/testTipDates/beast3-direct/testTipDates-direct.run.log
```

## Comparison targets

Compare the following shared traces:

- `posterior`, `prior`, and `likelihood`;
- `kappa`;
- `populationSize`;
- `clockRate`;
- tree height and tree length.

Before comparing marginal distributions, also inspect each generated XML and
tree file to confirm:

1. all 17 taxa are present;
2. the most recent tip has age `0`;
3. the oldest tip has age `38`;
4. one dated tree is connected to the coalescent prior and likelihood;
5. one strict-clock rate parameter is estimated;
6. BEAST 3 direct/XML use the same date convention;
7. BEAST X direct/XML use the same date convention.

This example should only be marked complete when both the dated-tree semantics
and the posterior distributions agree across all five paths.
