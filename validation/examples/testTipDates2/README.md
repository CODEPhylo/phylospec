# testTipDates2

## Purpose

This example is derived from the `testTipDates2.xml` file distributed with
BEAST 2.7.7. It is the second dated-tip coverage case and uses the primate
alignment from the distributed example.

The inputs are maintained as:

- `reference/beast2-original.xml`: the unmodified BEAST 2 example;
- `reference/beast2-aligned.xml`: the controlled BEAST 2 comparison model;
- `testTipDates2.nex`: the original 12-taxon primate alignment, with an
  `_age0` or `_age1` suffix added to each taxon name so both PhyloSpec
  backends can parse the fixed ages;
- `testTipDates2.phylospec`: the manually maintained PhyloSpec model.

The PhyloSpec source is not generated by translating the XML.

## Controlled model

All five paths represent:

- the 12-taxon, 898-site primate nucleotide alignment;
- fixed relative sampling ages:
  - `Lemur_catta_age1` and `M_fascicularis_age1` have age `1`;
  - the remaining ten taxa have age `0`;
- one HKY substitution model;
- `kappa ~ LogNormal(logMean=1.0, logSd=0.5)`;
- `baseFrequencies ~ Dirichlet(1, 1, 1, 1)`;
- constant population size fixed to `1.0`;
- an estimated tree with a constant-population coalescent prior;
- a strict molecular clock fixed to `1.0`;
- no gamma-distributed rate variation;
- a chain length of 10,000,000 and random seed `1234`.

PhyloSpec parses the relative ages from the taxon-name suffixes with:

```text
age=parse(regex=".*_age([01])$")
```

The aligned BEAST 2 XML expresses the same values with an `age` `TraitSet`.

## Why the aligned XML differs from the original

The distributed BEAST 2 example initializes `Lemur_catta` and
`M_fascicularis` at age `1`, gives their tip-date statistic a
`Uniform(0, 1)` density, and uses `TipDatesRandomWalker` to change those tip
heights during MCMC.

PhyloSpec currently attaches parsed ages to an alignment as fixed metadata.
It does not yet expose a stochastic tip-age declaration, a tip-only
calibration for a selected taxon set, or a cross-engine tip-date operator.
Consequently, pretending to reproduce the original sampled-age model would
create five paths with different state spaces.

This controlled benchmark fixes the two ages at their original value of `1`
and removes the uncertain-age density and operator from the aligned BEAST 2
XML. It preserves the original alignment, HKY likelihood, constant
coalescent, and strict clock. It also replaces the improper `OneOnX` kappa
prior with the proper log-normal prior used by all five paths and makes the
flat frequency prior explicit as `Dirichlet(1,1,1,1)`.

Therefore this example validates parsing and propagation of a sparse
fixed-age pattern. Full reproduction of the distributed sampled-tip-date
model remains a separately documented language/backend coverage gap.

## 1. Aligned BEAST 2 reference

```bash
mkdir -p validation/target/testTipDates2/beast2-reference

{
  /usr/bin/time -p "/Applications/BEAST 2.7.7/bin/beast" \
    -beagle \
    -beagle_CPU \
    -beagle_double \
    -overwrite \
    -seed 1234 \
    -prefix "$PWD/validation/target/testTipDates2/beast2-reference/" \
    "$PWD/validation/examples/testTipDates2/reference/beast2-aligned.xml"
} 2>&1 | tee \
  validation/target/testTipDates2/beast2-reference/testTipDates2-beast2.run.log
```

## 2. PhyloSpec to BEAST 3 direct

```bash
mkdir -p validation/target/testTipDates2/beast3-direct

mvn -pl validation/beast3/java -am \
  -Pvalidation-beast3-direct \
  -DskipTests \
  -Dphylospec.validation.source=validation/examples/testTipDates2/testTipDates2.phylospec \
  -Dphylospec.validation.outputPrefix=validation/target/testTipDates2/beast3-direct/testTipDates2-direct \
  -Dphylospec.validation.seed=1234 \
  -Dphylospec.validation.expectedLog=validation/target/testTipDates2/beast3-direct/testTipDates2-direct.log \
  -Dphylospec.validation.operatorSummary=validation/target/testTipDates2/beast3-direct/testTipDates2-direct.operators.txt \
  verify 2>&1 | tee \
  validation/target/testTipDates2/beast3-direct/testTipDates2-direct.run.log
```

## Comparison targets

Compare the following shared traces:

- `posterior`, `prior`, and `likelihood`;
- `kappa`;
- the four base frequencies;
- tree height and tree length.

Before comparing marginal distributions, also inspect each generated XML and
tree file to confirm:

1. all 12 taxa are present;
2. exactly ten taxa have age `0`;
3. `Lemur_catta_age1` and `M_fascicularis_age1` have age `1`;
4. one dated tree is connected to the coalescent prior and likelihood;
5. the strict-clock rate and constant population size are fixed to `1.0`;
6. BEAST 3 direct/XML use the same date convention;
7. BEAST X direct/XML use the same date convention.

This example should only be marked complete when both the dated-tree semantics
and the posterior distributions agree across all five paths.
