# testYuleOneSite

## Purpose

This example is derived from the `testYuleOneSite.xml` file distributed with
BEAST 2.7.7. It retains the original four taxa and one-site nucleotide
alignment and turns the original density smoke test into a controlled
five-path posterior comparison.

The inputs are maintained as:

- `reference/beast2-original.xml`: a reference copy preserving the effective
  model structure of the distributed BEAST 2 example;
- `reference/beast2-aligned.xml`: the controlled BEAST 2 comparison model;
- `testYuleOneSite.nex`: the original four identical one-base sequences;
- `testYuleOneSite.phylospec`: the manually maintained PhyloSpec model.

The PhyloSpec source is not generated by translating the XML.

## Controlled model

All five paths represent:

- four taxa named `A`, `B`, `C`, and `D`;
- one nucleotide site, with state `A` for every taxon;
- a JC69 substitution model;
- an estimated tree with a Yule prior;
- a birth rate fixed to `1.0`;
- a strict molecular clock fixed to `1.0`;
- no gamma-distributed rate variation;
- a chain length of 10,000,000 and random seed `1234`.

## Why the aligned XML differs from the original

The distributed XML is a short implementation smoke test rather than a
posterior analysis:

- its chain length is only `10`;
- its sequence likelihood is commented out;
- it attaches both a Yule density and a zero-death Birth–Death density to the
  same tree;
- it includes an unrelated single-child `TreeParser` state node;
- `birthRate` is placed in the state but has no active operator.

PhyloSpec expresses a tree as the result of one generative tree distribution.
It therefore cannot honestly represent the product of two alternative tree
generators as though it were one model.

The controlled benchmark keeps the part identified by the example name: the
one-site data and Yule tree model. It removes the second Birth–Death density
and parser-only state node, fixes the birth rate at its original value, and
enables the same JC69 likelihood in all five paths.

This benchmark validates Yule prior and one-site likelihood parity. It does
not claim to reproduce the two-density numerical smoke test in the original
file.

## 1. Aligned BEAST 2 reference

```bash
mkdir -p validation/target/testYuleOneSite/beast2-reference

{
  /usr/bin/time -p "/Applications/BEAST 2.7.7/bin/beast" \
    -beagle \
    -beagle_CPU \
    -beagle_double \
    -overwrite \
    -seed 1234 \
    -prefix "$PWD/validation/target/testYuleOneSite/beast2-reference/" \
    "$PWD/validation/examples/testYuleOneSite/reference/beast2-aligned.xml"
} 2>&1 | tee \
  validation/target/testYuleOneSite/beast2-reference/testYuleOneSite-beast2.run.log
```

## 2. PhyloSpec to BEAST 3 direct

```bash
mkdir -p validation/target/testYuleOneSite/beast3-direct

mvn -pl validation/beast3/java -am \
  -Pvalidation-beast3-direct \
  -DskipTests \
  -Dphylospec.validation.source=validation/examples/testYuleOneSite/testYuleOneSite.phylospec \
  -Dphylospec.validation.outputPrefix=validation/target/testYuleOneSite/beast3-direct/testYuleOneSite-direct \
  -Dphylospec.validation.seed=1234 \
  -Dphylospec.validation.expectedLog=validation/target/testYuleOneSite/beast3-direct/testYuleOneSite-direct.log \
  -Dphylospec.validation.operatorSummary=validation/target/testYuleOneSite/beast3-direct/testYuleOneSite-direct.operators.txt \
  verify 2>&1 | tee \
  validation/target/testYuleOneSite/beast3-direct/testYuleOneSite-direct.run.log
```

runs.

## Comparison targets

Compare:

- `posterior`, `prior`, and `likelihood`;
- the Yule tree-prior density;
- tree height and tree length.

Before comparing marginal distributions, confirm:

1. all five paths contain exactly four taxa and one nucleotide site;
2. every sequence contains `A`;
3. the birth rate is fixed to `1.0` and is not in the MCMC state;
4. exactly one Yule density and one JC69 likelihood are connected to the
   posterior;
5. the strict-clock rate is fixed to `1.0`;
6. direct and XML paths select the same state variables within each backend.

This controlled example should be marked complete only after all five runs
finish and the shared posterior and tree-statistic distributions agree.
